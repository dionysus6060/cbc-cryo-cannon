# Local runtime dependency

If you prefer a separate compile dependency, place the Fungal Infection: Spore
2.2.0j NeoForge JAR here as:

`spore-1.21.1-2.2.0j.jar`

The normal setup keeps the JAR in `run/mods/`; the Gradle build recognizes both
locations. The local JAR is needed for a complete development game runtime and
is intentionally not redistributed.
